# Support

For a broken link or factual correction in this profile, use the [issue tracker](https://github.com/magrathean-uk/magrathean-uk/issues) and include the affected section plus a public reference.

For help with a product, follow the support information on its site or repository linked from the [profile](README.md). This repository does not contain the applications listed there.

For company, consultancy, or commercial enquiries, use the [contact page](https://magrathean.uk/contact/) or email <contact@magrathean.uk>.

For vulnerabilities or accidental disclosure of private data, follow [SECURITY.md](SECURITY.md). Keep sensitive details out of public issues and pull requests.
